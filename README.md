# First Look · Cell Evidence Mini Lab

A standalone, browser-based mini lab for the Learning Module 3 discussion. Estimated initial activity time: 10–15 minutes.

## Files

- index.html — activity page and styling
- app.js — microscope illustrations, observations, evidence reveal, and downloads
- .nojekyll — lets GitHub Pages serve this as a plain static site

## Upload to GitHub Pages

1. Extract this ZIP on your computer.
2. Open the GitHub repository you want to use for this activity.
3. Upload the contents of this folder, with index.html and app.js together at the repository root. Upload the extracted files, not the ZIP or enclosing folder.
4. Enable GitHub Pages for the branch containing these files, using the repository root as the publishing folder.
5. Open the Pages address GitHub provides. Confirm the specimen image appears, enter practice observations, save the initial record, and test both image and discussion-record downloads before assigning it.
6. Put that Pages address in Canvas as the activity link. Test it in a student-access context.

If uploading into a subfolder of an existing Pages site, keep index.html and app.js together and use that subfolder's published address.

No installation, build command, external assets, AI service, API key, or ChatGPT login is required by this code. GitHub repository and Pages access settings determine who can access the published page.

## Student workflow

Choose one of three mystery preparations. Adjust focus and magnification, inspect numbered cells, and record two observations, a tentative interpretation, and needed evidence. Save the initial record, download the PNG and discussion record, then post the image and your own explanation in Canvas by Wednesday. After posting, return to reveal supplied identification evidence and write a revision for Sunday. Follow the instructor's Canvas deadlines.

Evidence opens only after an initial record is saved and the student selects the acknowledgement button; no calendar or Canvas-post verification occurs. The saved initial words and snapshot remain unchanged in the interface, but this is not an authorship-verification system.

## Notes and downloads

Notes are stored in the current browser on the current site address. They do not move from the original ChatGPT-hosted version to GitHub, between devices, or between browsers. Downloads provide a portable copy. Downloaded HTML records open independently and include the preserved image; they are not importable backups. No records are sent to an instructor or automatically submitted to Canvas. Browser storage may be unavailable, cleared, or full; download before leaving.

## Scientific scope and accessibility

All imagery consists of simulated bright-field illustrations, not microscopy photographs. Slides represent an archaeal example, budding yeast, and a diatom. Identification and nuclear-marker results are supplied fictional research evidence. Size, shape, pigmentation, or failure to see a nucleus cannot alone establish cellular organization or distinguish Bacteria from Archaea. Scale bars are calibrated to illustration dimensions. Zoom enlarges the scene without revealing new organelles. Focus blur is illustrative.

Text descriptions accompany the canvas image. Controls use native form elements, visible focus outlines, and a clear-view shortcut. Color is supplemented by shapes, numbered cells, and text. Initial records and revisions are separate.
